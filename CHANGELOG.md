## 0.0.1

* Initial release of `rolling_number_ticker`.
* Mechanical slot-machine vertical digit rolling animations for Flutter.
* Independent rolling cylinder columns for each individual digit.
* Static character pass-through for currency symbols, commas, decimals, and prefixes/suffixes.
* Directional roll physics (upwards on value gain, downwards on value drop).
* Delta status flash pulse (subtle green glow on increase, red flash on decrease).
* Formatting helpers for currency codes, thousands separators, and fixed precision.
* Fully customizable duration, curves, text styles, and staggered column delays.
